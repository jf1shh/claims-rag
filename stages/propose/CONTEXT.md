# ICM Propose Stage

## Inputs

- Findings report from Sense.
- Approved design and implementation plan.
- Repository conventions and risk-control matrix.

## Process

Turn one or more related findings into a bounded work order. State the affected interfaces, expected behavior, acceptance criteria, security impact, tests, and verification commands. Do not implement while proposing.

## Checkpoints

- Confirm the work order does not exceed the approved scope.
- Confirm every acceptance criterion has a verification command.
- Confirm security-sensitive changes identify their threat boundary.

## Audit

Record the finding IDs, affected files, rationale, risk level, and human approval reference before implementation begins.

## Outputs

A reviewed work order or implementation-plan task for `stages/act/CONTEXT.md`.
